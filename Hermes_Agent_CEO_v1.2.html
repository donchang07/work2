INTRO · 왜 HERMES인가

AI는 언제 먼저 움직이는가 — 먼저 말을 거는 에이전트 7종과 Hermes

ChatGPT 같은 챗봇은 물어봐야 답합니다. 요즘 나오는 프로액티브 에이전트는 정해진 시간이나 외부 신호에 맞춰 먼저 일하고 먼저 보고합니다. 그중 Hermes Agent는 세 가지 점에서 CEO 실습용으로 고를 만합니다.

FREE · 무료 오픈소스
라이선스 비용 0원

MIT 라이선스 오픈소스입니다. 설치·사용·수정·사내 배포에 비용이 들지 않고, 구독료나 좌석당 요금이 없습니다.

단, AI 모델 비용은 별도입니다. API 키 종량제, Nous Portal 정액($20부터), 기존 구독 재활용, 무료·로컬 모델 중에서 고릅니다. 아래 요금 비교를 참고하십시오.

SELF-IMPROVING · 스스로 성장
쓸수록 일을 더 잘합니다

공식 소개가 “self-improving AI agent”입니다. 여러 단계로 된 일을 해내거나 대표님께 방법을 교정받으면 그 절차를 스킬(SKILL.md)로 스스로 저장하고, 다음에 같은 일을 할 때 꺼내 쓰며 고쳐 나갑니다.

대표님에 대한 기억(USER.md), 배운 사실(MEMORY.md), 지난 대화 검색이 쌓이고, 큐레이터가 주기적으로 오래된 스킬을 정리합니다.

ON MY PC · 내 컴퓨터에서 작동
데이터가 내 PC에

대화 기록·기억·스킬·설정이 모두 대표님 노트북(%LOCALAPPDATA%\hermes)에 저장됩니다. Hermes 자체는 사용 통계를 보내지 않으며, 대화 내용은 설정한 모델 회사로만 갑니다.

대신 노트북이 켜져 있어야 일합니다. 꺼지거나 절전이면 텔레그램에 답하지 않고 예약 작업도 쉽니다. 설치·업데이트·백업·보안도 내 책임입니다. 24시간이 필요하면 사내 서버나 클라우드 VM에 설치합니다.

먼저 움직이는 세 가지 방식

스케줄정해진 시각에 실행. 예: 평일 오전 8시 브리핑
이벤트외부 신호가 오면 실행. 예: 새 GitHub 이슈, 슬랙 멘션, 웹훅
셀프 웨이크에이전트가 다음 확인 시점을 스스로 정함. 예: 미완료 작업 재확인
한국인이 만든 에이전트 · 피클(Pickle)

피클은 한국인 창업팀(박채근 대표 등)이 미국 실리콘밸리에 세운 스타트업 Pickle이 만든 휴대폰용 개인 AI 에이전트 앱입니다. Y Combinator 등의 투자를 받았고, 2026년 11월 10일 기준 국내 애플 앱스토어 생산성 무료 앱 다운로드 1위에 올랐습니다(중앙일보 보도).

  • 하는 일 — 말로 시키면 전화 걸기, 기차표 예매, 주문, 친구와 약속 잡기를 대신합니다. 네이버 메일·정부24·코레일(KTX)·캐치테이블·요기요·쿠팡 등 한국 서비스와의 연결이 강점입니다.
  • 먼저 움직이는 방식 — 예약 작업(Scheduled)을 1회·매일·매주·매월로 걸 수 있고(예: “매일 아침 메일 훑고 챙길 것 알려줘”), 맡긴 일을 추적하려고 피클이 스스로 예약 작업을 만들기도 합니다. 재입고 확인 같은 후속 알림도 먼저 보냅니다.
  • 피클끼리 대화 — 친구도 피클을 쓰면 두 비서가 서로 메시지를 주고받으며 일정을 조율합니다.
  • 안전장치 — 비밀번호·카드번호는 휴대폰에서 만든 키로 암호화해 Vault에 두고 AI에게 넘기지 않습니다. 결제·예약처럼 되돌리기 어려운 일은 먼저 내용과 금액을 보여 주고 동의한 범위에서만 실행합니다.

Hermes와 다른 점: 피클은 설치·서버 관리가 필요 없는 클라우드 서비스형 생활 비서이고, Hermes는 내 PC에 설치해 데이터·모델을 직접 통제하는 업무용 오픈소스 비서입니다. 피클의 대화와 기억은 피클 서버에 저장되며, 회사 공식 설명상 권한 있는 직원이 운영·안전 목적으로 열람할 수 있고 모든 열람은 기록됩니다. 언론 시험 사용에서는 AI 음성 전화를 상대가 스팸으로 여겨 끊거나, 사용자 동의 없이 지인·식당에 전화했다는 불만 후기도 보도됐습니다.

PART 1

Hermes Agent 한 장 이해

Hermes Agent는 Nous Research가 MIT 라이선스로 공개한 오픈소스 AI 에이전트입니다. 내 컴퓨터에서 상시 실행되면서 텔레그램·슬랙 등으로 지시를 받고, 대화에서 배운 것을 기억하며, 정해진 시간에 스스로 일을 합니다. 모델은 Claude, GPT, Gemini 등 원하는 것을 연결합니다.

구분Claude CodeHermes Agent
주 용도프로덕트 개발 (코드 작성·테스트)대표 업무 (브리핑·요약·모니터링·초안)
부르는 곳터미널터미널 + 텔레그램·슬랙·이메일 등 메신저

대표님이 기억할 네 가지 파일

파일역할Windows 위치
SOUL.md비서의 정체성과 말투 (예: 한국어 존대말, 결론 먼저)%LOCALAPPDATA%\hermes\SOUL.md
USER.md대표님에 대한 기억 (이름, 선호, 일하는 방식). 비서가 스스로 기록%LOCALAPPDATA%\hermes\memories\USER.md
MEMORY.md비서가 배운 사실과 환경 메모. 비서가 스스로 기록%LOCALAPPDATA%\hermes\memories\MEMORY.md
AGENTS.md특정 작업 폴더의 지침 (회사 개요, KPI 정의 등). Hermes를 그 폴더에서 실행할 때 읽힘작업 폴더 (이 교재에서는 C:\Users\내이름\hermes)

USER.md는 약 1,375자, MEMORY.md는 약 2,200자 한도가 있어 핵심만 남도록 설계되어 있습니다 (공식 문서 Persistent Memory 기준).

PART 2

사전 준비 — 설치 전에 세 가지를 손에 쥐고 시작합니다

설치 마법사는 중간에 API 키, 텔레그램 봇 토큰, 내 텔레그램 숫자 ID를 묻습니다. 미리 메모장에 모아 두면 설치가 끊기지 않습니다.

2-1. PC용 텔레그램 설치와 휴대폰 연결

단계 1
텔레그램 데스크톱 설치

desktop.telegram.org에서 Windows용을 받아 설치합니다. 실행하면 QR 코드가 나옵니다.

단계 2
휴대폰으로 QR 스캔

휴대폰 텔레그램 → 설정 → 기기 → 데스크톱 기기 연결(기기 추가) → PC 화면의 QR을 찍으면 PC에 내 대화방이 그대로 열립니다.

PC에서 하는 이유: 봇 토큰처럼 긴 문자열을 복사·붙여넣기 하기 쉽습니다.

2-2. 내 텔레그램 숫자 ID 확인

Hermes는 허락된 사람만 봇을 쓰도록 숫자 ID로 문을 잠급니다. 이 ID는 사용자 이름(@아이디)도, 봇 이름도 아닌 숫자입니다.

단계 1
@userinfobot 검색

텔레그램 검색창에 @userinfobot을 입력해 들어가 시작(Start)을 누릅니다.

단계 2
Id 숫자 메모

답장으로 오는 Id: 123456789 같은 숫자를 메모장에 적어 둡니다.

2-3. BotFather로 내 비서 봇 만들기

단계 1
@BotFather 열기

검색창에 @BotFather (파란 체크 표시가 있는 공식 계정) → 시작.

단계 2
/newbot 입력
나: /newbot BotFather: Alright, a new bot. How are we going to call it? 나: 장동인 비서 ← 표시 이름 (아무 이름이나) BotFather: Now let's choose a username for your bot. It must end in `bot`. 나: hermes_donchang_bot ← 전 세계에서 유일해야 함, bot으로 끝남
단계 3
토큰 복사

BotFather가 8788282020:AAF…처럼 숫자:영문 형태의 토큰을 줍니다. 메모장에 붙여 둡니다.

토큰은 봇의 열쇠입니다

토큰을 아는 사람은 누구나 봇을 조종할 수 있습니다. 슬라이드·단톡방에 올리지 마십시오. 노출되었다면 BotFather에서 /revoke로 즉시 폐기하고 새로 받습니다.

2-4. Anthropic API 키 만들기

단계 1
Claude Console 로그인

console.anthropic.com에 로그인 → Billing에서 결제 수단 등록과 크레딧 충전.

단계 2
지출 한도 설정

Limits(사용량 한도)에서 월 지출 상한을 정합니다. 첫 달은 실험 예산으로 작게 시작하길 권합니다.

단계 3
API Key 발급

API Keys → Create Key → 이름 hermes-노트북 → sk-ant-api…로 시작하는 키를 복사합니다. 이 화면을 닫으면 다시 볼 수 없습니다.

왜 구독(OAuth)이 아니라 API 키인가

Hermes 공식 문서에 따르면 Anthropic OAuth 경로는 Claude Max 요금제 + 추가 사용량 크레딧이 있을 때만 동작하고, Claude Pro 구독자는 쓸 수 없습니다. API 키는 쓴 만큼만 과금되고 콘솔에서 한도를 걸 수 있어 임원 실습에 적합합니다. 메뉴 이름은 Anthropic 콘솔 개편에 따라 달라질 수 있습니다.

메모장에 모일 세 가지

API 키 : sk-ant-api03-…… 봇 토큰 : 8788282020:AAF…… 내 숫자 ID : 123456789

PART 4

설치 명령 한 줄씩

아래 블록을 위에서부터 한 블록씩 붙여넣고 Enter를 누릅니다. 각 줄이 무엇을 하는지 바로 아래에 적어 두었습니다.

4-1. 작업 폴더 만들기

PowerShell
# 내 홈 폴더(C:\Users\내이름)로 이동
cd ~
# 비서 작업 폴더 만들기 — 이후 AGENTS.md와 작업 파일을 여기에 둡니다
mkdir hermes
cd hermes

이미 폴더가 있다는 오류가 나도 괜찮습니다. 그대로 cd hermes만 하면 됩니다.

4-2. 한글이 깨지지 않게 창 설정

PowerShell
# 이 창의 문자 코드를 UTF-8로 (한글·이모지 깨짐 방지)
chcp 65001
$env:PYTHONIOENCODING="utf-8"
$env:LANG="ko_KR.UTF-8"
# 콘솔 색상·커서 제어 코드를 켜기 (내 계정에만 적용, 관리자 불필요)
Set-ItemProperty -Path "HKCU:\Console" -Name "VirtualTerminalLevel" -Type DWord -Value 1

Hermes는 실행할 때 스스로 UTF-8로 전환하므로 이 단계는 보험입니다. 오래된 콘솔에서 설치 메시지가 깨지는 것을 막습니다.

4-3. Hermes 설치 (핵심 한 줄)

PowerShell · 공식 설치 스크립트
irm https://hermes-agent.nousresearch.com/install.ps1 | iex
  • irm = 인터넷에서 설치 스크립트를 내려받기, iex = 그 스크립트를 실행하기.
  • 관리자 권한이 필요 없습니다. 설치 위치는 %LOCALAPPDATA%\hermes (보통 C:\Users\내이름\AppData\Local\hermes)입니다.
  • Git, uv, Python, Node.js, ripgrep, FFmpeg, 브라우저 도구를 알아서 설치합니다. 미리 깔아 둘 것은 없습니다.
  • 설치가 끝나면 이어서 설치 마법사가 질문을 시작합니다 → PART 5로.

회사 망에서 위 주소가 막혀 있으면 같은 스크립트의 GitHub 원본 주소를 씁니다.

PowerShell · 대체 주소 (GitHub)
irm https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.ps1 | iex
설치 중에는 창을 닫지 마십시오

단계마다 한 줄씩 진행 상황이 표시됩니다. 10~20분 걸릴 수 있습니다(인터넷 속도에 따라 다름). 실패하면 마지막 몇 줄과 로그 위치(%LOCALAPPDATA%\hermes\logs\install.log)가 나옵니다. 같은 명령을 다시 실행하면 이어서 복구합니다.

참고 — 질문 없이 설치만 먼저 하고 싶을 때

PowerShell · 비대화형 설치
& ([scriptblock]::Create((irm https://hermes-agent.nousresearch.com/install.ps1))) -NonInteractive

이 경우 설치 후 새 창에서 hermes setup을 실행해 같은 마법사를 시작합니다.

## 말하는 방식
- 항상 한국어 존대말로 답한다.
- 결론을 먼저, 근거는 그다음 3줄 이내.
- 숫자는 단위와 기준일을 함께 쓴다.
- 모르는 것은 모른다고 말하고, 추정이면 "추정"이라고 밝힌다.

## 일하는 원칙
- 이메일 발송, 결제, 파일 공유, 외부 게시처럼 밖으로 나가는 일은 실행 전에 반드시 내 승인을 받는다.
- 고객·임직원 개인정보는 요약에 실명 대신 이니셜로 쓴다.
- 보고서는 1페이지를 넘기지 않는다.

저장 후 새 대화(/new)부터 적용됩니다. 메모장에서 저장할 때 인코딩은 UTF-8(기본값)을 유지합니다.

8-2. 기억시키기 — USER.md · MEMORY.md

두 파일은 비서가 대화 중에 스스로 기록합니다. 대표님은 말로 알려주면 됩니다.

나: 기억해 주세요. 저는 ○○주식회사 대표 장동인입니다. 보고는 결론 먼저, 표로 받는 걸 선호합니다. 매주 월요일 9시 임원회의가 있고, 주요 KPI는 월 매출·신규 고객 수·이탈률입니다.
PowerShell
# 비서가 나에 대해 기억한 내용 확인
notepad "$env:LOCALAPPDATA\hermes\memories\USER.md"
# 비서가 배운 사실·환경 메모 확인
notepad "$env:LOCALAPPDATA\hermes\memories\MEMORY.md"

기억은 다음 대화부터 반영됩니다. 같은 대화 안에서 “기억했나요?”라고 확인하면 헷갈릴 수 있으니 /new 후 “제 이름과 선호하는 보고 방식이 뭐죠?”로 확인합니다.

8-3. AGENTS.md — 회사 컨텍스트를 작업 폴더에

PowerShell
notepad "$HOME\hermes\AGENTS.md"
AGENTS.md 예시
# 회사 컨텍스트

## 회사 개요
- 회사: ○○주식회사 / 업종: B2B SaaS / 임직원 120명
- 핵심 제품: ○○ (제조 현장 품질 데이터 분석)

## 고객과 경쟁
- 핵심 고객군: 매출 1,000억 이상 제조사 품질팀
- 경쟁사: A사, B사, C사

## KPI 정의
- 월 매출(MRR): 월 구독 매출 합계, 원 단위
- 신규 고객: 해당 월 첫 결제 고객 수
- 이탈률: 전월 고객 중 해당 월 미갱신 비율

## 폴더 규칙
- 보고서는 reports\ 폴더에 YYYYMMDD_제목.md 로 저장

AGENTS.md는 Hermes를 그 폴더에서 시작할 때 읽힙니다 (cd ~\hermes 후 hermes). SOUL.md와 기억은 어디서 시작하든 항상 적용됩니다.

PART 9

CEO 실습 6가지

모두 텔레그램에 자연어로 보내면 됩니다. 명령어를 외울 필요가 없습니다. 실습마다 “확인할 것”으로 결과를 검증합니다.

실습 1 · 매일 아침 7시 브리핑 예약

텔레그램 → 평일 아침 7시(한국 시간)마다 다음을 1페이지로 정리해서 이 대화방으로 보내주세요. 1) 우리 업계(제조 AI·품질 분석) 주요 뉴스 5건과 한 줄 시사점 2) 경쟁사 A사·B사·C사의 새 소식 3) 원/달러 환율과 전일 대비 변화 마지막에 "오늘 대표가 결정할 것" 한 줄을 붙여주세요.

예약이 잘 됐는지 확인하고, 내일까지 기다리지 말고 지금 한 번 돌려 봅니다.

PowerShell
# 예약 작업 목록 (ID와 다음 실행 시각 확인)
hermes cron list
# 지금 즉시 한 번 실행 — <ID>를 목록의 ID나 이름으로 바꿉니다
hermes cron run <ID>

PowerShell에서 직접 예약할 수도 있습니다. 이때는 결과를 텔레그램으로 보내라고 --deliver telegram을 꼭 붙입니다 (터미널에서 만든 예약의 기본 전달처는 내 PC 파일입니다).

PowerShell
hermes cron create "0 7 * * 1-5" "업계 뉴스 5건, 경쟁사 소식, 환율을 1페이지로 요약" --timezone Asia/Seoul --name "아침브리핑" --deliver telegram

"0 7 * * 1-5" = 분 0, 시 7, 매일, 매월, 월~금. 시간대를 빠뜨리면 노트북 설정 시간대를 따릅니다.

실습 2 · 보고서 PDF를 1페이지로

텔레그램 → (PDF 파일 첨부) 이 보고서를 임원회의용 1페이지로 요약해 주세요. 형식: 핵심 결론 3줄 / 숫자 표 / 우리 회사에 주는 시사점 3가지 / 원문 쪽수 표시.

실습 3 · 음성 메모로 회의록

텔레그램 → (마이크 버튼을 길게 눌러 1~2분 음성 메모) "오늘 영업회의 내용입니다. 3분기 목표 대비 85퍼센트, 대형 고객 두 곳 계약 지연..." 이어서 → 방금 음성을 회의록으로 정리해 주세요. 결정사항 / 후속조치(담당·기한) 표로.

음성은 PC에서 로컬로 받아쓰기(Faster-Whisper)되어 별도 키가 필요 없습니다. 첫 사용 때 모델(약 150MB)을 내려받아 조금 느립니다. Windows ARM 노트북에서는 로컬 받아쓰기가 지원되지 않습니다.

실습 4 · 경쟁사 감시 (주 1회)

텔레그램 → 매주 금요일 오후 5시에 A사·B사·C사의 홈페이지 보도자료, 채용 공고, 가격 변경을 확인해서 "영향도 높음/중간/낮음"으로 분류해 보내주세요. 높음이 없으면 "특이사항 없음" 한 줄만.

웹 검색은 키 없이도 무료 계층으로 동작합니다. 사용량이 많아지면 속도 제한이 걸릴 수 있어, 상시 운영 시 유료 검색 키 등록을 검토합니다(hermes tools).

실습 5 · 엑셀 숫자 분석

텔레그램 → (월별매출.xlsx 첨부) 최근 12개월 매출 추이를 차트 이미지로 그리고, 전월 대비 10% 이상 변한 달과 그 원인 가설 3개를 적어 주세요.

실습 6 · 반복 업무를 Skill로 저장

텔레그램 → 방금 회의록 만든 방식을 "회의록정리"라는 스킬로 저장해 주세요. 다음부터는 음성만 보내면 이 형식으로 정리되게 해 주세요.
PowerShell
# 설치된 스킬 목록
hermes skills list
# 공식 허브에서 스킬 검색 (예: 구글 워크스페이스 연동)
hermes skills search google

저장된 스킬은 /회의록정리처럼 슬래시 명령으로도 부를 수 있습니다. 스킬 파일은 %LOCALAPPDATA%\hermes\skills\에 SKILL.md로 쌓여 나중에 신규 직원 매뉴얼의 원천이 됩니다.

PART 10

안전 수칙 — 임원 노트북이라면 꼭

Hermes는 대표님 계정 권한으로 명령을 실행합니다. 기본값도 안전하게 설계되어 있지만(위험 명령 승인, 민감 파일 쓰기 차단, 비밀값 가림, 응답 없으면 거부), 업무 PC라면 한 단계 더 조입니다.

기본으로 켜져 있는 보호의미
위험 명령 승인 (smart)삭제·디스크 조작 같은 위험 명령은 실행 전 판단, 애매하면 승인 요청
무응답 = 거부승인 요청에 300초 동안 답이 없으면 실행하지 않음
민감 경로 쓰기 차단.ssh, .aws, .env 등 자격증명 파일은 고칠 수 없음
비밀값 가림API 키·토큰처럼 보이는 문자열은 로그와 대화에서 가려짐
메신저 허용 목록허용 ID가 없으면 모든 사용자를 거부
원격 수집 없음Hermes 자체는 사용 통계를 보내지 않음. 대화는 설정한 모델 제공사로만 전송

추가로 조이기

PowerShell
# 위험 명령은 항상 내가 직접 승인 (자동 판단 끄기)
hermes config set approvals.mode manual
# 파일 수정 전 자동 스냅샷 → 대화 중 /rollback 으로 되돌리기
hermes config set checkpoints.enabled true
# 설정 파일을 직접 보고 싶을 때
notepad "$env:LOCALAPPDATA\hermes\config.yaml"

절대 실행되면 안 되는 명령은 config.yaml에 금지 목록으로 넣습니다.

config.yaml 에 추가
approvals:
  mode: manual
  deny:
    - "git push --force*"
    - "*curl*|*sh*"
    - "dd if=* of=/dev/*"

Hermes는 Windows에서도 명령을 Git Bash로 실행하므로 금지 패턴은 bash 명령 기준으로 씁니다. 패턴은 반드시 따옴표로 감쌉니다. 저장하면 재시작 없이 바로 적용됩니다.

텔레그램에서 승인하기

비서가 위험 작업 승인을 요청하면 봇 대화방에서 /approve(이번만 승인) 또는 /deny(거절)로 답합니다. /yolo(모든 승인 생략)는 쓰지 마십시오.

하지 말 것 세 가지
  • 허용 사용자 목록을 비우거나 GATEWAY_ALLOW_ALL_USERS=true 설정 — 봇 아이디만 알면 누구나 대표님 PC에 명령할 수 있게 됩니다.
  • API 키·봇 토큰을 Windows 사용자 환경변수에 넣기 — 모든 프로그램이 볼 수 있습니다. .env에만 둡니다.
  • 고객 개인정보·미공개 실적을 검증 없이 외부 모델에 대량 투입 — 사내 정보보호 규정을 먼저 확인합니다.

문제 해결

막히면 이 순서로 확인합니다: hermes doctor → hermes status → hermes gateway status → hermes logs errors.

증상원인해결
설치 직후 hermes를 인식하지 못함열려 있던 창은 새 PATH를 모름창을 닫고 새로 열기. 급하면 & "$env:LOCALAPPDATA\hermes\bin\hermes.exe"
스크립트 실행이 차단됨 / 백신이 막음회사 보안 정책·백신IT 담당자에게 %LOCALAPPDATA%\hermes\bin 예외 등록 요청. 보안 프로그램을 임의로 끄지 마십시오
irm 주소 접속 실패회사 망 차단PART 4의 GitHub 대체 주소 사용, 또는 IT에 허용 요청
텔레그램 봇이 답이 없음게이트웨이 정지, 노트북 절전, 허용 ID 오류hermes gateway status → hermes gateway restart. 허용 ID가 숫자인지 확인
봇이 “권한 없음”으로 거부허용 ID에 봇 이름 등 잘못된 값notepad "$env:LOCALAPPDATA\hermes\.env"에서 TELEGRAM_ALLOWED_USERS=내숫자ID로 고친 뒤 재시작
답이 비거나 오류 (401·인증)API 키 오타·잔액 부족Console에서 잔액 확인 → hermes model 다시 설정
한글이 ?로 보임오래된 콘솔Windows Terminal 사용. HERMES_DISABLE_WINDOWS_UTF8가 설정되어 있지 않은지 확인
아침 브리핑이 안 옴노트북 꺼짐, 전달처가 localhermes cron list로 전달처 확인, hermes cron doctor. 노트북 절전 해제
로그인 후 게이트웨이가 자동 시작 안 됨그룹 정책이 작업 스케줄러 차단schtasks /Query /TN Hermes_Gateway /V /FO LIST로 원인 확인
/edit를 눌러도 편집기가 안 뜸편집기 미지정기본은 메모장. VS Code를 쓰려면 $env:EDITOR = "code --wait"

ai4ceo의 .env를 ~\hermes에 복사Windows의 Hermes는 %LOCALAPPDATA%\hermes\.env만 읽음. ~\hermes의 .env는 읽히지 않음마법사에서 키 입력, 또는 hermes config set ANTHROPIC_API_KEY
PowerShell을 관리자 모드로 실행설치에 관리자 권한 불필요. 작업 스케줄러도 일반 권한으로 등록일반 PowerShell로 안내
핸드북 부록 A의 /init user|soul|agents, /show, /mode, /brief, /find, /schedule, /audit, /backup, /mcp list공식 슬래시 명령 목록에 없음. /init은 폴더를 스캔해 AGENTS.md를 만드는 명령실제 명령(/cron, /memory, /skills, /usage 등)과 자연어 지시로 대체
USER.md·SOUL.md·AGENTS.md가 모두 ~/.hermes/에SOUL.md는 Hermes 홈, USER/MEMORY는 memories\, AGENTS.md는 작업 폴더PART 1·8 위치표
텔레그램 토큰을 ~/.hermes/config.yml에 저장비밀값은 .env, 일반 설정은 config.yamlPART 11·12 반영
Claude Pro/Max 구독(OAuth) 선택지OAuth는 Max + 추가 크레딧에서만 동작, Pro는 불가API 키 방식 유지 (기존 판단과 동일)
