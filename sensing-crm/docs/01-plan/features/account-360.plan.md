# Plan — account-360

| 항목 | 값 |
|---|---|
| feature | account-360 (PDCA 8/9) |
| 범위 | SCR-005 고객 목록, SCR-006 고객 360 |
| FR / SC | FR-039~FR-042 / SC-032, SC-033 (+ SC-040 고객 부분) |

## 목표
고객명·별칭 검색과 세그먼트 필터, 그리고 신호·활동·주문·위험·추천·품질을 한 화면에 모은 고객 360을 제공한다. 앞선 feature의 결과를 소비하는 통합 화면이다.

## 작업 순서
1. `GET /api/accounts`, `GET /api/accounts/{id}`(F1의 권한 스텁을 실제 응답으로 교체)
2. SCR-005, SCR-006(차트·타임라인·카드 3개)
3. E2E: SC-032, SC-033, SC-040, SC-009(목록 범위)
