# Plan — quality-lab

| 항목 | 값 |
|---|---|
| feature | quality-lab (PDCA 9/9) |
| 범위 | SCR-010 품질-성과 실험실 |

## 목표
강의의 핵심 장면. 정답 이탈 고객 6곳이 심어진 같은 정답 세계를 자동화 비율 0·25·50·75·100%로 다시 생성(11.9 열화)하고, 같은 규칙으로 품질·이탈 탐지 재현율·정밀도·추천 적중률을 비교한다. 운영 DB는 바꾸지 않는다.

## 작업 순서
1. `lib/domain/lab.ts` (`evaluate`, `runLab`) — 순수 함수
2. `GET /api/lab`, `POST /api/lab/run`
3. SCR-010 화면(설명·실행·비교 표·선 차트·핵심 메시지·이력)
4. 통합: SC-034 / E2E: SC-035, SC-036
5. 최종: 전체 회귀 + localhost:3000 기동

## 사전 실측 (Plan 근거)
`npx tsx scripts/lab.ts` — 기준일 4개(2026-08-20, 2026-11-09, 2026-12-15, 2027-03-01) 모두 같은 결과: 종합 품질 0.694→0.959(단조 증가), 재현율 0.167→1.000(차이 0.833), 정밀도 1.0, 추천 적중률 0.458→1.000. 가설 목표(재현율 ≥0.80, 차이 ≥0.30)를 열화율 조정 없이 충족.
