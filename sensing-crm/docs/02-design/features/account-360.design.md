# Design — account-360

## API
- `GET /api/accounts?q=&segment=` → 범위 내 활성 고객. 검색은 정규화(공백·법인 표기 제거, 소문자) 후 고객명·별칭 부분 일치. 행: 세그먼트·담당 KAM·최근 12개월 주문액·위험 점수/등급·품질 점수.
- `GET /api/accounts/{id}` → 범위 밖 403, 없음 404. 응답: 고객·별칭, 타일(최근 3개월 주문액·직전 3개월 대비 증감률·마지막 확정 접촉 경과일·위험 점수), 월별 주문 12개월, 타임라인(신호·활동 최신 30), 위험 근거 상위 3, 1순위 새 추천, 고객 품질 점수·열린 이슈 수.

## 화면
- SCR-005: 검색(300ms 디바운스)·세그먼트 Select·표(행 클릭 → 360). 모바일은 카드 목록.
- SCR-006: PageHeader(이름·세그먼트·별칭) → StatTile 4 → 좌(BarChart 월별 주문, Timeline) / 우(위험 근거, 다음 행동, 품질 카드) → "미팅 노트 작성"은 `/notes?account={id}`.
- 오류: `SCR-005-ERROR`, `SCR-006-ERROR`, 없는 고객은 "고객을 찾을 수 없습니다" + 고객 목록 버튼.
